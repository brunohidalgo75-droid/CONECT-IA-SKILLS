# Modo agencia y servicio freelance

## Separación de clientes

Cada marca debe tener una ficha independiente. No reutilices oferta, tono, audiencia, datos, testimonios ni restricciones de otro cliente.

Si el usuario quiere continuidad entre sesiones, ofrece crear una estructura local como:

```text
clientes/
  nombre-cliente/
    ficha-marca.md
    diagnostico-instagram.md
    estrategia.md
    calendario-15-dias.md
    contenidos/
```

Crea o modifica esos archivos solo cuando el usuario lo solicite o confirme. La skill no mantiene una base de datos ni sincroniza clientes automáticamente.

## Onboarding de un cliente

Recopila:
- Datos del negocio y contacto responsable (sin pedir información sensible innecesaria).
- Oferta prioritaria.
- Público y zona de atención.
- Objetivo comercial y objetivo de contenido.
- Diferenciación y evidencias disponibles.
- Tono y referencias aprobadas.
- Recursos para grabación.
- Restricciones y proceso de aprobación.
- Frecuencia, volumen y fecha de entrega acordados.

## Definir un servicio vendible

Ayuda al freelancer a especificar:
- Cliente ideal y problema que resuelve.
- Entregables concretos (por ejemplo, diagnóstico, pilares, 8 o 12 guiones, historias y calendario).
- Qué no incluye (grabación, edición, publicación, pauta, community management, sesiones extra).
- Número de rondas de cambios.
- Responsabilidades del cliente (información, aprobación, grabación y tiempos).
- Plazos y forma de entrega.
- Precio propuesto y supuestos.

Si no conoce su mercado, presenta el precio como hipótesis para validar. No inventes tarifas estándar ni garantices que podrá vender el paquete.

## Propuesta comercial básica

Estructura:
1. Situación o necesidad que el prospecto compartió.
2. Objetivo del servicio.
3. Qué se entregará.
4. Cómo será el proceso.
5. Qué necesita aportar el cliente.
6. Qué no está incluido.
7. Plazo y precio propuesto.
8. Próximo paso.

No afirmes haber auditado una cuenta si no la revisaste. No uses falsa escasez, resultados garantizados ni mensajes masivos engañosos.

## Muestra de portafolio

Si se usa una marca ficticia, escribe “EJEMPLO FICTICIO — NO ES UN CLIENTE REAL”. Si se usa un negocio real, pide autorización antes de presentar el material como trabajo realizado para ese negocio. No fabriques testimonios ni casos de éxito.

## Capacidad y rentabilidad

Ayuda a calcular horas de investigación, estrategia, redacción, revisiones y coordinación. Recomienda limitar el alcance para que el precio cubra el tiempo real. No aconsejes vender producción ilimitada por una tarifa fija.
